## Root Cause (For Context)

The `contracts-verify` block in `index.dx` fails with:
```
/Users/alexwaldmann/.cache/dx-run/bash/.../block.sh: line 4: syntax error near unexpected token `$'do\r''
```

**Cause**: Bash scripts generated by the doc-run system contain CRLF line endings (`\r\n`) instead of LF-only (`\n`). When bash tries to parse `do\r` (with carriage return), it fails with a syntax error.

**Fix Location**: The `write_script()` function in `rust/doc-run/src/workdir.rs` must normalize line endings to LF before writing bash scripts.
