## The Failed Item

The `contracts-verify` block in `index.dx` was failing with bash syntax errors:
```
/Users/alexwaldmann/.cache/dx-run/bash/.../block.sh: line 4: syntax error near unexpected token `$'do\r''
```

The root cause: bash scripts generated by doc-run on Windows were using CRLF line endings (`\r\n`), which bash on macOS/Linux doesn't recognize. The `\r` character caused a syntax error.

- **Change**: Modified `write_file()` function to normalize CRLF→LF for `.sh` files

